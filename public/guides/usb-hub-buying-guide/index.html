USB Hub เลือกยังไงให้คุ้ม?

จำนวนพอร์ตเยอะไม่ได้แปลว่าคุ้มกว่าเสมอ เพราะ USB Hub แต่ละรุ่นต่างกันทั้งความเร็วข้อมูล การชาร์จผ่าน PD และการรองรับจอภาพ

เริ่มจากพอร์ตที่ใช้จริง

ถ้าแค่เพิ่ม USB-A สำหรับเมาส์ คีย์บอร์ด และแฟลชไดรฟ์ รุ่น 4 พอร์ตพื้นฐานอาจเพียงพอ แต่ถ้าต้องต่อจอ การ์ด SD หรือชาร์จโน้ตบุ๊กผ่านสายเดียว ค่อยขยับไป USB-C Hub แบบหลายฟังก์ชัน

ดูความเร็วข้อมูล

USB 3.x เหมาะกับอุปกรณ์ที่ต้องส่งข้อมูลเร็วกว่า USB 2.0 เช่น SSD ภายนอก แต่ความเร็วจริงยังขึ้นกับพอร์ตต้นทาง สาย และอุปกรณ์ที่ต่อด้วย

PD Pass-through ไม่ได้แปลว่าจ่ายไฟเต็มเสมอ

Hub ที่มีช่อง USB-C PD สามารถรับไฟจากหัวชาร์จแล้วส่งต่อให้โน้ตบุ๊กได้ แต่ตัว Hub เองอาจใช้ไฟบางส่วน จึงควรดูสเปกกำลังรับเข้าและกำลังที่ส่งออกจริง

จะใช้ HDMI ต้องเช็กเครื่องต้นทาง

USB-C บนโน้ตบุ๊กทุกช่องไม่ได้รองรับภาพออกจอเหมือนกัน ถ้าจะซื้อ Hub ที่มี HDMI ควรตรวจว่าเครื่องรองรับวิดีโอผ่าน USB-C ตามมาตรฐานที่ต้องใช้

เช็กลิสต์: พอร์ตที่ใช้จริง → Data Speed → PD → HDMI/Video → Card reader → ความยาวสาย → ความร้อน/วัสดุ → ประกัน → ราคา
